# E-Commerce Sales & Customer Analytics

## 📌 Project Overview
This project uses SQL to analyze e-commerce sales and customer data. The goal is to understand sales performance, identify top-performing products, and explore customer purchasing behavior.

## 🎯 Business Objectives
- Analyze total sales and revenue.
- Identify top-selling products.
- Analyze sales by category.
- Explore customer purchasing behavior.
- Examine sales trends.
- Generate business insights using SQL.

## 🛠️ Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

## 📂 Project Structure
- `sql/` — SQL scripts for database creation and analysis.
- `data/` — E-commerce dataset.
- `screenshots/` — Screenshots of SQL queries and results.
- `README.md` — Project documentation.

## 🔍 SQL Concepts Used
- SELECT, WHERE and ORDER BY
- GROUP BY and aggregate functions
- JOINs

- Common Table Expressions (CTEs)
